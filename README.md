# Blazor PokéAPI

Uma aplicação web desenvolvida com **Blazor WebAssembly e C#**, que utiliza a [PokéAPI](https://pokeapi.co/) para consumir informações do universo Pokémon.

O projeto tem como objetivo explorar o desenvolvimento de aplicações web com .NET, integração com APIs REST e construção de interfaces interativas utilizando Blazor.

## 🚀 Tecnologias utilizadas

- **C#** — Linguagem de programação.
- **.NET 10** — Plataforma de desenvolvimento.
- **Blazor WebAssembly** — Framework para construção da interface web.
- **HTML5 e CSS3** — Estrutura e estilização da aplicação.
- **PokéAPI** — API REST utilizada como fonte de dados.

## 📌 Funcionalidades

A aplicação foi desenvolvida para trabalhar com informações do universo Pokémon por meio da integração com a PokéAPI.

## ⚙️ Como executar o projeto

### Pré-requisitos

Antes de começar, você precisará ter instalado:

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Git](https://git-scm.com/)

### 1. Clone o repositório

```bash
git clone https://github.com/MarryKukles/blazor-pokeapi.git
```

### 2. Acesse a pasta do projeto

```bash
cd blazor-pokeapi
```

### 3. Restaure as dependências

```bash
dotnet restore
```

### 4. Execute a aplicação

```bash
dotnet run
```

Após iniciar, acesse o endereço local informado pelo terminal para visualizar a aplicação.

## 🌐 API utilizada

O projeto utiliza a [PokéAPI](https://pokeapi.co/), uma API pública e gratuita que disponibiliza informações sobre Pokémon, habilidades, tipos, movimentos e diversos outros dados.

Documentação: https://pokeapi.co/docs/v2

## 🎯 Objetivos do projeto

- Praticar desenvolvimento web com C# e Blazor WebAssembly.
- Aprender a consumir APIs REST.
- Trabalhar com requisições HTTP e manipulação de dados.
- Desenvolver interfaces utilizando componentes Razor.
- Aprofundar conhecimentos no ecossistema .NET.
